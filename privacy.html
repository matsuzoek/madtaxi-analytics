プライバシーポリシー

制定日：2026年10月3日

「MAD TAXI Analytics」（以下「本ツール」）は、YouTube チャンネル「Mad Taxi」の運営者が、自分のチャンネルの分析データを確認するために使う運営者専用のツールです。本ツールが Google アカウントのデータをどのように扱うかを以下に定めます。

1. 取得する情報

本ツールは、利用者（チャンネル運営者本人）が Google の認証画面で許可した場合に限り、次の読み取り専用の権限で情報を取得します。

  • YouTube アカウントの閲覧（youtube.readonly）：チャンネル情報と動画の一覧
  • YouTube アナリティクスの閲覧（yt-analytics.readonly）：再生回数・視聴時間・流入元などの統計
  • YouTube 収益レポートの閲覧（yt-analytics-monetary.readonly）：推定収益などの統計

動画の投稿・編集・削除、コメントの投稿など、データを変更する権限は一切求めません。

2. 利用目的

取得した情報は、運営者が自分のチャンネルの成績を分析し、動画制作の改善に役立てる目的にのみ使います。

3. 保存と管理

取得した情報と認証用のトークンは、運営者のパソコン内にのみ保存します。外部のサーバーには送信・保存しません。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。広告目的にも使いません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。本ツールは YouTube API サービスを使用しており、利用者には YouTube 利用規約と Google プライバシー ポリシーが適用されます。

6. アクセスの取り消しとデータの削除

本ツールへのアクセスは、Google アカウントのセキュリティ設定（サードパーティ製のアプリとサービス）からいつでも取り消せます。取り消し後は、保存していたトークンと取得データを運営者のパソコンから削除します。
